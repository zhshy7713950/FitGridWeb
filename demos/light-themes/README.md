# FitGrid 浅色皮肤 Demo

用于选择视觉方向的独立静态原型，不接入账号、真实数据或正式主题。

在项目根目录运行：

```sh
python3 -m http.server 4321 --bind 127.0.0.1 --directory demos/light-themes
```

打开 <http://127.0.0.1:4321/>。也可以直接在浏览器中打开 `index.html`。

| 方案 | 主背景 | 主操作 | 视觉处理 |
| --- | --- | --- | --- |
| 晴空蓝 | `#F3F6FB` | `#3865CD` | 白色导航、紧凑圆角、无衬线数字 |
| 松石绿 | `#EFF4F0` | `#287463` | 雾绿导航、柔和大圆角、轻阴影 |
| 暖瓷橙 | `#F7F4EF` | `#A4602D` | 暖白导航、琥珀细线、小圆角、衬线数字 |

交互：三款切换、并排对比、记住选择、名称/代码搜索、方向筛选、选择产品查看配置、网格明细弹窗。其余业务操作仅显示原型提示。

地址参数：`?theme=azure`、`?theme=jade`、`?theme=porcelain`；`?view=compare` 打开对比。参数优先于浏览器本地保存的选择。

产品名称、最高价、每份金额参考 `src/features/grids/demo-grid-data.ts`。此处仅展示六个品种，其中纳指 ETF 被设为做空以预览状态样式。网格阶梯按最高价的固定 5% 幅度示意，未调用正式算法；预算合计为六个产品的每份金额之和。页面中的统计与价格均为固定演示数据。

选定方向后再将主题变量接入正式界面，处理现有硬编码深色表面、深浅模式持久化与系统偏好。本轮不修改现有业务代码。
