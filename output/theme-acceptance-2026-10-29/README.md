## 验证结果

- 主题与对比度测试：15 项通过，包含初始化、记忆、存储异常、标签页同步、键盘切换及文字对比度回归。
- 全部前端测试：574 项通过。
- 除主机运维脚本外的完整应用测试：842 项通过、17 项按环境跳过，包含全部 10 项浏览器冒烟测试。
- 首屏在 React 资源尚未加载时恢复已保存深色；刷新、跨页面、跨标签页、退出与重新登录保持选择；系统深色不会改变首次默认浅色。
- 全部主要页面及菜单、导出弹窗、网格行明细检查两套主题；320、390、768、1440px 无新增整页横向溢出。
- `pnpm run typecheck`、`pnpm run lint`、`pnpm run build` 均通过。
- 独立审查提出的两处对比度问题已补测试、修正并复验。

验证边界：未声称整仓所有测试通过。默认并发下，未改动的运维脚本测试出现超时；其中一个超时用例单独复核通过。随后限制并发的完整运维补测仍有一个备份／恢复测试工作进程长时间运行，超过七分钟后结束并清理，未取得该组的完整结论。以上 842 项应用测试独立运行并全部通过。

主要命令：

```sh
pnpm exec vitest run --exclude 'src/server/ops/**' --maxWorkers=4 --testTimeout=15000
pnpm run typecheck
pnpm run lint
pnpm run build
```

## 本地预览

在项目根目录运行 `pnpm run dev:ui --port 4322`，打开 <http://127.0.0.1:4322/grids>。

主题覆盖正式组件，`dev:ui` 只用于无需数据库的本地验收。登录页、邀请页与登录后的账号栏都提供切换入口。没有添加账号同步或后端字段。
