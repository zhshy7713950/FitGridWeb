# FitGrid 浅色／深色换肤实施记录

用户已批准：以 A「晴空蓝」为默认皮肤，保留现有布局和功能；深色沿用现有视觉；当前浏览器记住最近选择，登录退出后不清除，不增加账号同步或数据库字段。

## 实施步骤

1. 为初始化、双向切换、持久化、异常存储、标签页同步及键盘操作编写测试，验证失败后接入主题管理。
2. 统一全局颜色与页面内的深色覆盖，保留交易颜色含义，接入账号栏、登录及邀请页切换入口。
3. 验证首屏、跨页、刷新、登录退出及不同屏幕宽度；运行类型检查、Lint 和测试，保存实际页面截图。

## 技术决定

- `html[data-theme]` 为当前页面会话的主题来源，使用 React `useSyncExternalStore` 订阅切换事件，避免增加 Context Provider 和重渲染业务子树。
- 在 head 中以固定脚本恢复 `fitgrid-theme`；初始化脚本创建并管理主题颜色及 color-scheme meta，确保页面正文绘制前完成，避免 React 重复创建被首屏脚本修改过的静态 meta。
- 两种模式为 `light` / `dark`；缺失、无效或无法读取的存储均默认浅色，不随系统变化。
- 存储写入失败不影响当前文档主题；localStorage 的 storage 事件同步标签页；忽略 sessionStorage 和无关键。
- 切换不重载、重挂载页面或修改表单值。Demo 文件仅作参考。
