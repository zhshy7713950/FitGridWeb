# API、认证与安全规格

## 1. API 约定

- 基础路径：`/api/v1`。
- 请求与响应：JSON；文件上传使用 `multipart/form-data`。
- 认证：同源安全 Cookie，不把长期 token 暴露给 JavaScript。
- 十进制：JSON 字符串。
- 时间：UTC ISO 8601。
- ID：UUID。
- 列表：`items`、`nextCursor`；默认 20，最大 100。
- 错误：统一错误信封。

```json
{
  "code": "PRODUCT_CODE_CONFLICT",
  "message": "产品代码已存在",
  "fieldErrors": {"productCode": ["当前账号已存在相同产品代码"]},
  "requestId": "01J..."
}
```

完整线格式见 [OpenAPI](contracts/openapi.yaml)。

## 2. 认证与邀请

### 首个管理员

- 部署完成后通过容器内 CLI 创建首个管理员。
- CLI 只在没有任何用户时允许无邀请创建管理员。
- 密码交互输入，不作为命令参数进入 shell history。
- 创建成功后无需在 `.env` 保存初始密码。

### 私有邀请

- 只有管理员可以创建邀请。
- 生成至少 256 bit 随机 token，数据库只保存 SHA-256/HMAC 摘要。
- 默认有效期 24 小时，最长 7 天。
- 邀请只能使用一次；消费与用户创建在同一事务完成。
- 页面可公开查询 token 是否有效，但不返回创建者、预期用户名或账号统计。

### 密码与会话

- 用户名规范化后全局唯一，3–64 字符。
- 密码 12–128 字符，交由 Better Auth 的安全密码散列处理。
- 登录错误不区分用户名不存在、密码错误和账号禁用。
- 会话默认 7 天，活动时滚动续期；修改密码时撤销其他会话。
- 退出删除当前会话；管理员禁用账号时撤销全部会话。
- 生产 Cookie：`HttpOnly`、`Secure`、`SameSite=Lax`、`Path=/`，不设置跨子域共享。

## 3. 授权矩阵

| 接口组 | 匿名 | 普通用户 | 管理员 |
|---|---:|---:|---:|
| 健康检查 | 是 | 是 | 是 |
| 登录、邀请状态、接受邀请 | 是 | 是 | 是 |
| 当前会话、退出、改密 | 否 | 是 | 是 |
| 自己的网格 CRUD | 否 | 是 | 是 |
| 自己的导入导出 | 否 | 是 | 是 |
| 创建邀请 | 否 | 否 | 是 |
| 账号列表与启禁用 | 否 | 否 | 是 |
| 读取其他用户产品 | 否 | 否 | 否 |

管理员角色不是数据超级用户。生产应用中不存在跨账号产品查询接口。

## 4. 跨账号访问规则

- 产品详情、更新、删除、重新计算：同时以当前 `ownerId` 和产品 UUID 定位。
- 其他账号 UUID 与不存在 UUID 都返回相同 404 错误。
- 搜索、计数、冲突检测、导入预检和导出都必须经过 owner-scoped store。
- 请求体、查询参数和上传文件中的 `ownerId` 一律拒绝为未知字段。
- 响应 DTO 不返回数据库 `ownerId`。
- 数据库 RLS 作为第二道隔离边界。

## 5. 状态码

| 状态 | 使用场景 |
|---:|---|
| 200 | 查询、更新、重新计算、登录成功 |
| 201 | 新增产品、创建邀请、接受邀请 |
| 204 | 退出、删除成功 |
| 400 | JSON/上传格式错误 |
| 401 | 未登录或会话失效 |
| 403 | 已登录但角色不足，仅用于管理接口 |
| 404 | 产品不存在或不属于当前账号；邀请无效 |
| 409 | 产品代码冲突、乐观锁冲突、邀请已使用 |
| 413 | 导入文件超限 |
| 422 | 字段或算法校验失败 |
| 429 | 登录、邀请或导入限流 |
| 500 | 未分类服务端错误 |
| 503 | 数据库不可用或服务未就绪 |

## 6. 安全控制

### 请求保护

- 所有状态变更请求校验 `Origin`/`Host`；同源 Cookie API 拒绝跨站来源。
- Next.js 与 Caddy 均限制请求体；导入端点上限 10 MiB。
- 严格 JSON Schema/DTO 校验，拒绝未知字段。
- 输出使用 JSON 序列化，不拼接 HTML。
- 文件下载设置安全的 `Content-Disposition` 和固定前缀文件名。

### 限流

单实例首期采用应用内限流并记录安全日志：

- 登录：每 IP+用户名 15 分钟 5 次失败，成功后清零。
- 邀请状态：每 IP 每分钟 30 次。
- 接受邀请：每 IP 每小时 10 次。
- 导入预检：每用户每分钟 5 次。
- 其余写接口：每用户每分钟 60 次。

限流状态重启后丢失是单实例首期可接受限制；扩容到多实例前必须迁移到共享存储。

### 秘密与日志

- `.env` 不进入 Git，生产权限 600。
- `BETTER_AUTH_SECRET`、数据库密码和备份加密密钥独立生成。
- 日志对用户名和用户 ID 做摘要，不记录输入密码、Cookie、邀请 token 或 JSON 文件正文。
- 错误响应只返回公开错误码和 requestId。

## 7. API 测试要求

### 账号隔离

1. A、B 分别创建产品，只能看见自己的列表。
2. A、B 可以使用相同 `productCode`。
3. A 对 B 的 UUID 执行 GET/PATCH/DELETE/recalculate，全部 404。
4. A 搜索 B 的名称或代码为空。
5. A 导入 B 已使用但 A 未使用的代码，不视为冲突。
6. A 导出不得包含 B 数据。
7. 管理员账号不能调用跨用户产品接口，因为接口不存在。

### 认证

- 无 Cookie 的保护接口返回 401。
- 普通用户调用管理接口返回 403。
- 过期、已使用和伪造邀请不可创建用户。
- 禁用账号不能登录，既有会话失效。
- 改密撤销其他会话。

### 输入与算法

- 十进制、范围、行数上限和未知字段校验。
- 产品代码冲突 409，编辑时允许保留自己的代码。
- 算法结果逐字段匹配黄金 fixtures。
- 重新计算幂等，且不改变输入、ID、owner 或创建时间。
